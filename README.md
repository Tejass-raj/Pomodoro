# 🍅 Pomodoro Timer using Python Tkinter

A productivity application built with Python's Tkinter library that implements the Pomodoro Technique. The app helps users stay focused by alternating between work sessions and short or long breaks, while providing a clean graphical interface and real-time countdown timer.

---

## 📖 Overview

The Pomodoro Timer is designed to improve focus and productivity by dividing work into timed intervals called Pomodoros. Each work session is followed by a short break, while a longer break is automatically scheduled after every four work sessions.

The application features a user-friendly graphical interface built with Tkinter, a live countdown timer, automatic session switching, reset functionality, and visual progress tracking using checkmarks. It is an excellent beginner project for learning GUI programming, event handling, timers, and state management in Python.

---

## ✨ Features

- 🍅 Pomodoro work timer (25 minutes)
- ☕ Automatic short and long breaks
- ⏱️ Live countdown timer
- ▶️ Start and Reset controls
- ✔️ Visual session progress tracking
- 🎨 Clean and intuitive GUI
- 🔄 Automatic timer transitions
